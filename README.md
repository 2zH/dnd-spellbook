# D&D 法术书 · 空间流动原型

一堆法术围绕着中央一本摊开的法术书漂移的前端原型，单个 HTML 文件，无构建、无依赖、无外部请求。

在线预览：https://2zh.github.io/dnd-spellbook/

## 交互

- 自动持续流动，鼠标移开也继续
- 拖动画面旋转视角，松手带惯性
- 点击某个法术，它飞进书页并计数
- 点击法术书，全部收入；再点一次全部散开
- 「收拢视野」把一圈法术吸向中心，再点展开
- 支持键盘聚焦与 `prefers-reduced-motion`

## 做法

- 24 个法术分布在一个球面上，按球坐标投影到屏幕，近大远小，按深度排序做前后遮挡
- 前景元素会从书前面经过，边缘自然裁切，不做围成一圈的平面轨道
- 图标固定在白色圆环内，法术名始终在圆环右侧，随深度只做温和的缩放
- 书本素材为生成图加抠图，叠了一层 SVG 刻线做书页纹样

## 素材

- 图标：生成模型产出的贴纸风格图标，切图后统一描边与配色
- 书本：生成图，去白底保留软阴影

## 与参考的关系

动效按参考视频的可见行为重建（铺满画面、前景穿越、边缘裁切、近大远小），非原站源码，也不代表使用了相同的实现。
